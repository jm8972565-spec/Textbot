# TextBot — реална AI версия

Готов стартов проект: frontend + Node.js backend + OpenAI Responses API.

## Стартиране
1. Инсталирай Node.js.
2. В папката изпълни `npm install`.
3. Копирай `.env.example` като `.env`.
4. В `.env` сложи своя API ключ.
5. Изпълни `npm start`.
6. Отвори `http://localhost:3000`.

**Важно:** никога не слагай OPENAI_API_KEY в `public/index.html` или друг browser/client файл.
